Politique sur les témoins

Configuration actuelle : seuls les témoins nécessaires sont actifs. Les outils de mesure sont préparés dans le code, mais leurs identifiants sont laissés vides.

Qu’est-ce qu’un témoin?

Un témoin est une petite donnée enregistrée par votre navigateur afin de mémoriser une préférence ou de permettre le fonctionnement d’un service.

Témoins nécessaires

Le site utilise le stockage local du navigateur pour mémoriser votre choix concernant la mesure d’audience. Cette fonction ne sert pas à créer un profil publicitaire.

Mesure d’audience

Google Analytics ou Google Tag Manager pourront être ajoutés ultérieurement. Ils ne seront chargés qu’après votre consentement et lorsque l’identifiant officiel aura été inséré dans analytics-config.js.

Publicité et Meta Pixel

Le Meta Pixel n’est pas activé dans cette version. Toute activation future devra être documentée et soumise au mécanisme de consentement approprié.

Modifier votre choix

Vous pouvez réinitialiser votre choix en effaçant les données du site dans les paramètres de votre navigateur. Une option visible de gestion des préférences pourra être ajoutée au moment du déploiement si le fournisseur de consentement retenu l’exige.
